# REPORT T-103 | status: DONE

## Files
- `data/processed/orbiters.json` — verified ephemerides and Keplerian orbital elements for active Mars orbiters (MRO, 2001 Mars Odyssey, ExoMars TGO, MAVEN, Mars Express) in the Mars equator-of-date inertial frame.
- `data/pipeline/fetch_orbiters.py` — script to query, format, and calculate periods and altitudes for active orbiters and update `data/processed/orbiters.json`.
- `data/pipeline/tests/test_orbiters.py` — unit test suite validating schema, parameter ranges, uniqueness, and two-body orbit propagation.
- `data/manifest.yaml` — catalog updated with `orbiters.elements` manifest entry.

## How to run
- Fetch orbiters:
  ```powershell
  & ".venv\Scripts\python.exe" "data\pipeline\fetch_orbiters.py"
  ```
- Run tests:
  ```powershell
  & ".venv\Scripts\python.exe" -m pytest "data\pipeline\tests\test_orbiters.py" -q
  ```
- Query live API:
  ```powershell
  curl "http://127.0.0.1:8000/api/v1/orbiters/states?utc=2026-11-14T12:00:00Z"
  ```
