## Files
- `data/pipeline/aoi.py` — loads `contracts/projection.json`; provides `aoi_bbox_geo()`, `aoi_crs()`, `geo_crs()`, `grid_for(resolution_m)` returning `(transform, width, height)`.
- `data/pipeline/cog.py` — `write_cog(path, array, transform, crs, nodata, meta_dict)` writing a Cloud-Optimized GeoTIFF (GDAL COG driver, DEFLATE, overviews) and LayerMeta JSON sidecar matching `contracts/openapi.yaml`.
- `data/pipeline/common.py` — updated shared helpers connecting `aoi.py` and `cog.py` with `gdal_env()`, `aoi_grid()`, `upsert_manifest()`, and `now_utc()`.
- `data/pipeline/make_l0_synthetic.py` — deterministic synthetic DEM generator at 20 m resolution on the Gale AOI grid with crater floor base, Mount Sharp mound rising to the south, 3 distinct ridges, and mild Gaussian noise seeded from `config/params.yaml`.
- `data/pipeline/README.md` — usage documentation for running pipeline scripts and tests.
- `data/pipeline/tests/test_aoi_cog.py` — pytest test suite verifying AOI geometry, grid consistency, COG write/read roundtrip, overviews, LayerMeta required fields, and determinism.
- `data/manifest.yaml` — catalog updated with `marsnav.synthetic_dem_20m` entry along with existing L1 entry.
- `data/processed/gale/L0/elevation.tif` — generated 20 m synthetic DEM COG.
- `data/processed/gale/L0/elevation.json` — LayerMeta sidecar for L0.

## How to run
- Run tests:
  ```powershell
  & ".venv\Scripts\python.exe" -m pytest "data/pipeline/tests" -q
  ```
- Generate L0 synthetic DEM:
  ```powershell
  & ".venv\Scripts\python.exe" "data/pipeline/make_l0_synthetic.py"
  ```
- Inspect L1 raster metadata:
  ```powershell
  & ".venv\Scripts\python.exe" -c "import rasterio; r=rasterio.open('data/processed/gale/L1/elevation.tif'); print(r.crs.to_proj4(), r.res, r.width, r.height, r.profile.get('tiled'))"
  ```
