GOAL: (a) data/processed/landing_sites.json for the globe, (b) a measured-position POV photo set for Gale in data/processed/gale/pov.json, (c) more named Gale places derived from rover positions by sol — all with provenance (decision D-13).

PROVENANCE RULES (read docs/DECISIONS.md D-13 first)
- A coordinate is accepted only if it is read from data: the MMGIS waypoint files (data/raw/msl/MSL_waypoints.json, key "sol" → lat/lon; helper loading code exists in data/pipeline/make_places_from_mmgis.py), the USGS planetary gazetteer, or a mission data file. Record the file/URL and how the number was extracted. A web page without coordinates is not evidence.
- Sol ranges for named places (Yellowknife Bay, Pahrump Hills, Vera Rubin Ridge, Glen Torridon, Gediz Vallis, …) must come from NASA mission blog posts or pages that state the sols; cite the URL per place.

DELIVERABLES
1. data/pipeline/make_landing_sites.py → data/processed/landing_sites.json: Curiosity (Gale), Perseverance (Jezero), Opportunity (Meridiani), Spirit (Gusev), InSight (Elysium Planitia), Zhurong (Utopia Planitia), Viking 1, Pathfinder, Phoenix — each {id, name, mission, year, lat, lon, status ("open" only for Gale; "locked" for the rest, label "Phase 2"), source_url, evidence}. Coordinates from the USGS gazetteer or each mission's official landing-site page that states them; if two sources differ by > 0.05°, report both and use the official gazetteer value.
2. data/pipeline/make_places_gale.py (extends places.json; keep ids gale.base, gale.boxwork_region, gale.rover_now unchanged): add Yellowknife Bay, Pahrump Hills, Vera Rubin Ridge, Glen Torridon, Gediz Vallis channel (and others you can document) with position = mean of MMGIS waypoints in the documented sol range, plus "sols", "source" and "evidence".
3. data/pipeline/make_pov.py → data/processed/gale/pov.json: ≤ 10 Curiosity raw images spread over those places. Find the real raw-image feed (NASA MSL raw images page https://mars.nasa.gov/msl/multimedia/raw-images/ and the JSON/API behind it — inspect the page's network requests with your browser tool; do not guess URLs). Each entry {url, thumbnail_url, camera, sol, credit "NASA/JPL-Caltech", lat, lon, position_quality}: lat/lon from the MMGIS waypoint with the SAME sol (position_quality "exact") or the nearest sol (then "approximate" and name the sol gap). Every image URL must answer HTTP 200 (record it). Do not commit image files; hot-link only.
4. Manifest entries (data/manifest.yaml) for each product with credit.
5. data/pipeline/tests/test_places_pov.py: schema checks, every place inside the AOI bbox of contracts/projection.json, every POV url field is https, sol→position matches the waypoint file.
