GOAL: orientation without GPS (the core of our pitch) — Orientation UI, time slider, back-to-base widget, HUD wiring and the TypeScript math port for offline use.

CONTEXT
- Endpoints (types in src/api/schema.d.ts): POST /localize/sun-compass {utc, approx_position, beta_deg, sigma_beta_deg, uses_shadow, sigma_pos_m} → {heading_deg, sigma_heading_deg, sun, warnings}; POST /localize/resection {site_id, observations[{landmark{place_id|lat,lon}, bearing_deg, sigma_deg}], heading_known, prior} → {position, xy, heading_deg, cov, ellipse{semi_major_m, semi_minor_m, angle_deg, p}, gdop, residuals_deg, converged, quality_flags}; GET /sun; POST /route/back-to-base {site_id, position, base?, profile} → {bearing_deg, distance_m, eta_s, dose_mSv, route}; POST /route/off-route {route_xy, position, recent_distances_m} → {distance_m, progress_m, reroute}.
- Mars has no global magnetic field: the UI must say so wherever a compass would be expected (decision from the product spec).
- Real landmarks for resection come from GET /sites/{id}/places (measured positions); the user picks 2–3 and types a bearing for each.

DELIVERABLES (your folders only)
1. src/orientation/SunCompassPanel.tsx: inputs (angle to sun or shadow, uncertainty), result heading with ± and warnings (low sun, overhead sun) and an SVG compass rose that shows the sun azimuth, the heading and the uncertainty arc; explicit note "No magnetic compass on Mars".
2. src/orientation/ResectionPanel.tsx: pick landmarks from the places list, enter bearings, choose heading known/unknown, show the fix, the 95 % error ellipse as an SVG scale diagram (axes in metres, landmark bearing lines), GDOP warning when quality_flags contains WEAK_GEOMETRY, and the residuals table.
3. src/orientation/OrientationPanel.tsx combining both with an "Apply to map" callback (position + ellipse) for W6; unit tests with mocked fetches.
4. src/ui/TimeSlider.tsx: simulation time slider (sol / LTST / Ls readouts from GET /sun), play/pause at accelerated speed, jump to "local noon" / "sunset", reduced-motion safe.
5. src/ui/BackToBaseWidget.tsx: always-visible azimuth arrow + distance + ETA + dose (props), updates from the API response.
6. src/hud/Hud.tsx wired to real props: heading tape from the sun-compass heading, next-waypoint bearing/distance, back-to-base, EVA dose/time/O2 left (from RouteResult totals and feasibility), nearest comms window (optional prop, empty-safe), "Recalculating…" state when off-route → reroute.
7. packages/marsnav-ts/ (your folder): TypeScript ports of F01 haversine, F02 bearing, F13 sun position needs Mars24 — port F11/F13 exactly from docs/MATH.md §3, F39 sun compass and F40 resection (Gauss–Newton) with no dependencies; golden test vectors file generated by the CEO's Python reference: packages/marsnav-ts/golden.json (the CEO will add it — until it exists, write the test harness and use the values in the Python tests packages/marsnav/tests/** as expected values). Web Worker wrapper in src/workers/marsnav.worker.ts.
