**D-01 (D0-1) · Сценарий, площадка, AOI.**
- Кратер Гейл, нижние склоны горы Шарп.
- Экипаж из двух астронавтов выходит из хабитата к обнажениям boxwork, отбирает образцы и возвращается в пределах лимита EVA.
- База (хабитат) по умолчанию — Bradbury Landing: 4,5895° ю. ш., 137,4417° в. д.
- **Предварительная AOI**: широта −4,89…−4,55, долгота 137,27…137,53 (~20 × 15 км), центр −4,72 / 137,40. Статус PROVISIONAL `[verify]`.
- W1 уточняет AOI по траверсу Curiosity и покрытию HiRISE DTM; для L2/L3 AOI может сузиться.
- Координаты района boxwork — `[verify]` (W1, по картам траверса).

**D-03 (D0-3) · Стек и версии.**
- Окружение: Python 3.12.10, Node 24.20.0, npm 11.19.0, Git 2.55.
- Python: numpy, scipy, numba, pyproj, rasterio (GDAL в колёсах), FastAPI, pydantic v2, uvicorn, httpx, pyyaml, cachetools; тесты — pytest + hypothesis; линтер — ruff. Версии закрепляются в `requirements.lock.txt` после установки.
- Frontend: React + TypeScript + Vite, Zustand, react-router, OpenLayers + proj4 + geotiff, three + @react-three/fiber + drei, uPlot (графики), vite-plugin-pwa, MSW, openapi-typescript, vitest, Playwright. Версии — в `package-lock.json`.
- Альтернативы: Recharts/visx вместо uPlot (тяжелее); CesiumJS вместо three (поддержка эллипсоида Марса не подтверждена).
